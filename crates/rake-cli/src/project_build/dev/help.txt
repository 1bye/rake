usage: rake [-h] [--target {desktop,web}] [--compiler {cargo,blaze}] [--live] [--manifest-path MANIFEST_PATH]
              [--package PACKAGE] [--bin BIN] [--features FEATURES]
              [--release | --debug] [--web-dir WEB_DIR] [--output OUTPUT]
              [--native-reloader NATIVE_RELOADER] [--restart-without-state] [--require-state]
              [--port PORT] [--instance INSTANCE] [--cdp] [--preview]
              [--no-open] [--json] [--verbose] [--session SESSION] [--base-path BASE_PATH]
              [--routing {path,hash}] [--sign-identity SIGN_IDENTITY]
              [--entitlements ENTITLEMENTS]
              {dev,build,bundle,doctor,inspect} [{status}]

Rake project builds and the development supervisor.

positional arguments:
  {dev,build,bundle,doctor,inspect}
  {status}

options:
  -h, --help            show this help message and exit
  --target {desktop,web}
  --live                Install/use the pinned experimental Blaze (Apple Silicon only)
  --compiler {cargo,blaze}
                        Desktop compiler; Blaze excludes Web
  --manifest-path MANIFEST_PATH
  --package, -p PACKAGE
  --bin BIN
  --features FEATURES
  --release
  --debug               Use a development profile, including for bundles
  --web-dir WEB_DIR
  --output OUTPUT
  --native-reloader NATIVE_RELOADER
                        External native backend; owns ABI/code retirement and
                        exits zero only after successful replacement
  --restart-without-state
                        Cargo: explicitly allow restart without a control endpoint
  --require-state
                        Blaze: block restarts that cannot preserve registered state
                        (also RAKE_REQUIRE_STATE=1)
  --port PORT
  --instance INSTANCE   Runtime UUID or application ID for CDP selection
  --cdp                 Expose opted-in runtimes to stock Chrome DevTools
  --preview             macOS 14+: print the native window preview URL
                        with pointer input and element selection; open it manually
  --no-open
  --json
  --verbose             Show supervisor events, session paths and full tool output
  --session SESSION
  --base-path BASE_PATH
                        Web bundle deployment prefix, such as /notes/
  --routing {path,hash}
                        Web bundle routing mode
  --sign-identity SIGN_IDENTITY
                        macOS bundle signing identity; default '-' uses ad-hoc
                        signing
  --entitlements ENTITLEMENTS
                        macOS signing entitlements plist
